# このさき — 画面モック

「働き方の選択肢を並べて比べる」アプリの5画面。
文字だけで議論していて形が掴めなくなったので起こしたもの。

| ファイル | 画面 |
|---|---|
| `Start.dc.html` | ① 初回の3問 |
| `Main.dc.html` | ② 3つを並べる（**主役**） |
| `Detail.dc.html` | ③ 1つの内訳（手取り・支出・30年グラフ） |
| `Phases.dc.html` | ④ 区切り（フェーズ）を編集 |
| `Shared.dc.html` | ⑤ 相方に届く読み取り専用画面 |

`shot-*.png` は上記をレンダリングしたもの。見るだけならこれで足りる。

## 中身の前提

すべて実例で作ってある（作り話の数字ではない）。

- 2027年4月、パートナーが正社員→パート。額面 380万 → 100万
- 子ども 2021年生まれ・2024年生まれ
- 運用 年4%、どの案も10年後にフルタイム相当（月18万）へ戻す想定

この前提での計算結果:

| | フル復帰 | 時短6h | パート |
|---|---|---|---|
| つみたて（月） | 18.0万 | 12.5万 | 5.2万 |
| 30年後 | 1億3,487万 | 1億1,687万 | 9,298万 |

## 守っている設計ルール

**金額の優劣を色で表現しない。** 低い数字を赤くしない。選択中は黒地に白、
それ以外は同じ濃さ。理由は、Life free で「収支がマイナスだと見たくなくて
記録しなくなった」が起きたため。**責める数字は、見られなくなる。**
