## 1. なぜこの的なのか（逆算の経路）

「このさき」（働き方の比較アプリ）が4回書き直しても固まらなかった原因は、
**私の頭の中から企画を出していたこと**でした。順算思考です。

今回は市場から逆に辿りました。**この経路そのものが資産**です。

```
① App Store 有料ランキング（カテゴリ別）を眺める
     → 金が実際に払われている場所を特定
② 「写真/ビデオ」に個人が勝てる形が集中していると分かる
③ 自分のドメイン（0〜7歳の子の親）と交差させる
④ 「月齢 カメラ」で検索 → ほぼ空席
⑤ 競合1本の461件のレビューを全部読む
⑥ 競合を実際にインストールして起動・撮影
```

⑥まで行って初めて「作るもの」が決まりました。

## 3. 競合：生後何日目カメラ

| | |
|---|---|
| 評価 | **461件・4.4★** |
| 価格 | 無料（広告あり） |
| カテゴリ | **ライフスタイル**（写真/ビデオですらない） |
| 開発 | 個人。13〜14年前リリース |

### 需要は13年分、実証されている

★1レビューなのに、ほぼ全員が「大好きだった」と書いている。

> 毎日愛用していただけに、**かなりショックです！何とかしてください！！！**
> 子どもの写真は**ずっとお世話になってきた**ので…大至急なんとかしてください！
> **子供が生まれた時から愛用**させて頂いています

レビューの日付は **13年前・12年前・11年前・10年前・5年前・4年前・1年前**。
**今も現役で使われている。**

### 作者本人が、直せないと書いている

> **「開発の者です」**（14年前・real-creative）
> 沢山不備が発生しており大変申し訳ございません orz こちらで現象が再現できておらず、
> **開発技術がいたらず改善できておりません。**

### 実物を触って分かったこと（ここが決定打）

| 画面 | 何が起きているか |
|---|---|
| 起動直後 | **一番上に楽天アフィリエイトのテキストリンク** |
| 起動直後 | **「生まれた日」を設定しないと撮れない**。1枚も撮らせてもらえない |
| 起動直後 | 画面の大半が**作者の手書きイラスト**。カメラが見えない |
| カメラ | **iOS標準のカメラピッカーそのまま**。独自UIが1つもない |
| 出力 | 写真の**下に白い帯**が足され、黒文字で `生後1082日目 (2歳11ヶ月) 2026/09/21 04:14` |

**白帯の何が悪いか**

1. 写真の比率が崩れる。インスタや家族LINEで帯だけ浮く
2. 写真そのものが1ミリも良くならない（オルディ等は逆に写真を美しくして売れている）
3. 情報が4つ全部入る。**`04:14` を必要とする人はいない**

> 帯そのものが悪いのではない。**あの帯が悪い。** ポラロイドは帯ごと商品になっている。

### バグについての訂正

★1の大半は10〜14年前のもので、**今はほぼ直っている**（4.4★がその証拠）。
「13年間直っていない」は読み違いだった。

**残っているのは「広告」（4年前）と「名前が消える」（1年前）、そしてデザイン。**
バグは直る。**デザインは直らない。** ここが足場になる。

## 4. 勝ち筋

機能はもう向こうにある。真似しなくていい。**体験だけで勝つ。**

```
開いたら、即カメラ。
撮ると「1歳3ヶ月」が、写真の中にきれいに入る。
広告なし。
```

| | 生後何日目カメラ | そだつ |
|---|---|---|
| カメラ | iOS標準をそのまま | **全画面プレビューの自前カメラ** |
| 入る場所 | 写真の下に白帯 | **写真の中に、控えめに** |
| 入る情報 | 日数・年齢・日付・時刻の4つ | **1つ**（既定は「1歳3ヶ月」） |
| 書体 | 選べない | 数種類から選ぶ |
| 最初の1枚 | 設定してから | **開いたらすぐ撮れる** |
| 広告 | 起動直後にアフィリエイトリンク | **なし** |

## 5. MVP

| | |
|---|---|
| 1 | **開いたら即カメラ**（全画面プレビュー。設定を先に求めない） |
| 2 | **撮ると、写真の中に月齢が入る** |
| 3 | 誕生日を登録（**複数人**） |
| 4 | カメラロールに保存 |
| 5 | **広告なし** |

### 子どもに全振りする

横展開（ペット等）は**別アプリ**を作ればいい。絞るほど強い。

- **表示が自動で切り替わる** — 0歳台は「生後128日」、1歳から「1歳3ヶ月」
  子ども特化でしか作れない親切
- **フラッシュは既定でOFF** — レビュー：「新生児の目の前でひかり、可哀想でした」
- スクショ・LPは赤ちゃんの写真で埋める
- 検索語：月齢 / 生後 / 成長記録 / ベビー

### MVPに入れないもの（v2以降）

レビューで要望されているが、**足すと長所を壊す**。

- アプリ内アルバム（要望2回）
- 過去写真をまとめて加工（要望3回）
- 無音シャッター（マナーカメラが¥850で4位＝金は払われている。
  ただし日本のiPhoneはシャッター音が強制で実装が重く、グレーな面もある）

> 褒められていたのは「**目的がはっきりしている、シンプルで素晴らしいapp**」。
> 足したら負ける。

## 6. 課金

```
無料        … 全機能つかえる。書体・フレームは1種類
¥480 買い切り … 書体・フレームが全部つかえる
```

**差別化（見た目）が、そのまま課金理由になる形。**
広告を入れないので「広告除去課金」は使えない（それは否定した相手の手）。

### 逆算の数字

月額ではなく買い切りなので、**毎月売り続ける必要がある**。

| ゴール | 必要な販売数 |
|---|---|
| 月1万円 | **毎月25本** |
| 月5万円 | **毎月123本** |

*¥480、Apple手数料15%（小規模事業者プログラム）→ 手取り408円/本*

### 市場規模の冷静な見積もり（ここは楽観しないこと）

```
競合は13年で461評価 = 年35評価
評価率1%と仮定      → 年3,500DL程度の市場
```

月5万＝**年1,476本の有料販売**。年3,500DLの市場で4割を有料で取る計算になり、
**現実的ではない。**

| ゴール | 判定 |
|---|---|
| **月1万円**（年300本） | **射程内** |
| 月5万円（年1,476本） | **いまの市場のままでは厳しい。広げる必要がある** |

**ただし天井ではない可能性がある。** 競合は**ライフスタイルカテゴリ**にいて、
カメラとして発見されていない。461評価は「見つけられた人だけ」の数字。
正しくカメラカテゴリに置いたとき母数がどう変わるかは、まだ分からない。

## 7. 5条件の採点

| | | |
|---|---|---|
| 市場が年商1,000万〜1億の帯 | 13年間需要が続いている | ○ |
| **その場所で金が払われている** | カメラ全般は◎（¥150〜350が売れている）。ただし**月齢カメラで金が払われた証拠はまだゼロ**。需要が確認できているのは「無料の月齢カメラ」 | **△** |
| **成果物が勝手に外に出る** | 子どもの写真は毎日SNS・家族LINEへ | ◎ |
| 個人が1〜2週間で作れる | カメラ＋日付計算＋焼き込み | ◎ |
| 自分が続けられる | 毎日使う | ◎ |

4.5/5。**「このさき」より明確に強いが、満点ではない。**（このさきは「金が払われる」「外に出る」の2つで落ちた）

**残っている未知数はただ1つ。**

> 需要が確認されているのは**無料の月齢カメラ**。
> 金が払われているのは**レトロカメラ**（別カテゴリ）。
> **この2つが交差する証拠は、まだ1つもない。**

そしてこれは**作っても分からない**。②LP → ③広告 で測るしかない。
今回の検証は「需要があるか」ではなく「**その需要は金を出すか**」を測るもの。

## 付録：「このさき」がなぜ落ちたか（学び）

| 視点 | このさき | |
|---|---|---|
| 市場規模 | 0〜7歳の世帯350〜400万 | ○ |
| 金額面 | **無料FP相談と無料家計簿が市場を埋めている** | ✕ |
| バズりやすさ | **家計の数字は人に見せない。拡散の燃料がゼロ** | ✕ |

ずらす方向が「競合から離れる」方には成功していたが、
**同時に、お金が動いている場所からも離れていた。**

正しいずらしは、競合からは離れるが**お金からは離れない**方向。
腕立て伏せ検知アプリは、フィットネスという金が動く市場の**内側**でずらしている。

`mock/` と `lp/` に残してあるものは、的が変わっても作り方として使い回せる。
