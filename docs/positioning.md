# Life free ポジショニング

2026-09 に整理。**ここが揺れると全部が揺れる**ので、機能追加やLPを書く前に必ずここを読むこと。

---

## 誰のためのアプリか

**0〜7歳の子がいる親。またはこれから子を持つ人。**

8歳以上に広げない。理由は下の「なぜ7歳で切るか」を参照。

## 何を解くのか

> ぼんやりとお金がかかるのは分かる。でも、
> **具体的に何年後に何にいくらかかるのか**がイメージできていない。
> そこに対して**今の資産運用で足りるのか**も分からない。

この「ぼんやりした不安」を、**具体的な時期と金額**に変える。

## 一行で言うと

**「一番きついのは、何年後か知っていますか」**

- 誰も即答できない（＝刺さる）
- 金額ではなく**時期**から入るのが新しい。他のシミュレーターは金額から入る
- 答えがアプリの中にある構造になる

---

## なぜ7歳で切るか

| 理由 | |
|---|---|
| 不安が最大で情報が最小 | 子が小さいほど先が長く、何も見えない。中高生の親はもう実感で分かっている |
| **まだ手が打てる** | 0歳なら大学まで18年、7歳でも11年。複利が効く時間が残っている |
| 住宅の判断時期と重なる | この層はまさに家を買うか決める時期。教育費と住宅ローンを同じ時間軸に乗せられる |

8歳以上を含めると「もう間に合わないかも」というメッセージになる。それは売り物にならない。

## 市場と競合

**市場規模**: 0〜7歳の子がいる世帯は概ね350〜400万世帯（8学年分、重複考慮の概算）。
数%に刺されば数万〜十万人規模。個人が戦えるニッチのサイズ。

**本当の競合は他の家計簿アプリではない。**

| 競合 | その弱点 |
|---|---|
| 無料FP相談 | ライフプラン表は作ってもらえるが、**保険を売られる** |
| 各社のライフプランシミュレーター | 単発。保存されない。翌年また一から入力 |
| 金融庁等の公的ツール | 「年収が毎年2%上がる想定」のような架空の数字 |
| マネーフォワード等 | 使用日ベースの記録。将来の話をしない |

**Life free の違い**:

> 予測が、自分の実績から出ている

月末の記録があるから「あなたは実際に月18万積み立てている」という**事実**から未来を引ける。
想像の数字ではない。だから信じられる。

---

## だから、記録は目的ではない

```
✗ 記録が主役 → 予測はおまけ（一番奥のタブ）
✓ 予測が主役 → 記録は予測の精度を上げる手段
```

現状のアプリは左の構造になっている。**主従が逆。**

### 初回に見せるべきもの

今は価値が出るまで最低2ヶ月かかる（先月比が出ない、グラフの点が1つ）。
競合は連携した瞬間に全部見える。ここで負けている。

あるべき姿:

```
入力3つ（子の年齢 / 今の貯金 / 月の積立）
        ↓ その場で
「一番きついのは2044年。上のお子さんが大学1年、下が高3。
  月◯万足りません。今から月◯万にすれば届きます」
```

**最初の30秒で、一番強い部分（予測）を出す。** 内訳も設定も後から足せばいい。

| | 現状 | あるべき |
|---|---|---|
| 主役のタブ | 記録 | 予測 |
| 初回の入力 | 設定9項目 + プロフィール + 記録8項目×2ヶ月 | 3項目 |
| 価値が出るまで | 2ヶ月 | 30秒 |
| 用語 | 「基本の投資余力」など説明が要る | 説明不要 |
| 住宅ローン | 扱えない | 教育費と同じ時間軸に乗せたい |

### 判明している事実

- 作った本人が「これ何のため？」と聞いた機能がある（ライフプラン）
- 記録が数ヶ月止まった時期がある。自分用の道具として使い続けられていない

**説明が必要な時点で負けている。** 他人はもっと使えない。

## 進め方の原則

需要検証を飛ばして作ってしまったが、詰んではいない。
**作ってある状態のほうが検証は強い**（モック画像ではなく実物を見せられる）。

検証の意味が変わるだけ。

| | 検証で決めること |
|---|---|
| 普通 | 作るかどうか |
| Life free | **これ以上進めるかどうか** |

この先に控えているのは全部重い作業（認証・データ分離・課金・iOS化）。
そこに何十時間も入れる前に、半日で反応を見る。

**LPの1行目が書けるかどうか自体がテスト。** 書けなければ、何を作っても売れない。

### 配布経路（ここが最大の弱点）

**現状、配れる先がない。** ここを甘く見積もると検証そのものが壊れる。

| チャネル | 現実 |
|---|---|
| note | 記事はあるが**フォロワー0** |
| X | アカウントなし |
| 知人 | 数人。うち子育て中が数人いる |

参考にした個人開発者は**フォロワー1.7万人**でX投稿 → 13,000imp → LP 100クリック
→ ウェイトリスト**1件**。1.7万人いても1件。

つまり「noteに1本出して反応を見る」は、フォロワー0では**検証にならない**。
ここを取り違えると「反応がなかった＝需要がない」と誤診する。
反応がないのは、**誰にも届いていないから**かもしれない。

### 検証はこの順で進める

| | やること | 費用 | 分かること |
|---|---|---|---|
| ① | LPを作る | 0円 | 1行目が書けるか＝差別化が言葉になるか |
| ② | 子育て中の知人3〜5人に直接見せる | 0円 | **伝わるか**。n=5でも「意味が分からない」ならアウト確定 |
| ③ | 既存コミュニティに置く（Threadsの住宅ローン・教育費の話題など） | 0円 | 生の反応。少量だが本物 |
| ④ | Meta広告 5,000円 | 5,000円 | **数**。ここで初めて率が測れる |

②で「意味が分からない」と言われたら、③④に進まずLPを書き直す。
③まで全部0円。④の5,000円は、この先に控える認証・データ分離・課金・iOS化の
数十時間と比べれば安い。

**判断ライン（④まで進んだ場合）**

| 結果 | 判断 |
|---|---|
| LP到達100人あたり登録3件以上 | 進む（認証・課金へ） |
| 1〜2件 | 文言かターゲットを1回だけ変えて再試行 |
| 0件 | 止める。自分用の道具として使い続ける |

**LP自体を診断ツールにする。** 読んで終わりではなく、その場で子の生年を入れると
ピーク年が出る。これなら「登録してくれるか」だけでなく「そもそも触ってくれるか」も測れる。

## やらないこと

一度に手を広げると全部途中で止まる。**1つ出し切るまで他は待たせる。**

| | 判断 |
|---|---|
| 認証・課金 | 反応を見てから |
| iOS化・App Store審査 | Webで配れる。年1万円のDeveloper Programも需要が見えてから |
| AI秘書・他エージェント連携 | 止める |
| 作品一覧サイト | 止める（載せるものが無い） |
