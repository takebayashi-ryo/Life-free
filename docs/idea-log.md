# 企画ログ — 落とした案と、その理由

**案そのものより、落とした理由が資産。** 同じ間違いを二度やらないために残す。

---

## 判断基準

### 1. 逆算の型（講師の実例から）

| | 元のカテゴリ | 足した能力 | 課金 | 結果 |
|---|---|---|---|---|
| 大学AIノート | ノート | **LLMが講義をまとめる** | 年6,000円 | 無風で月1万 |
| サブスクBox | 管理 | 一覧にする | 買い切り | バズで月10万 |

共通点は **「いままで人がやっていた判定・作業を、機械に渡している」**。
表示を変える・パラメータを変えるのは**ずらしではない**。

### 2. 月3万円の式（2026-09-22 追加）

*Apple 小規模事業者プログラム 手数料15% → 手取り85%*

| モデル | 月3万に必要なもの | 性質 |
|---|---|---|
| 買い切り ¥480 | **毎月74本を、ずっと** | 1年目も5年目も74本。積み上がらない |
| サブスク 年3,000円 | **141人が継続** | 月12人ずつ増えれば1年で到達 |
| サブスク 年6,000円 | **71人が継続** | 大学AIノートと同じ単価 |

> **目標が月3万なら、買い切りは実質選べない。**
> 毎日〜毎週使われ、AIなどのランニング原価があり、サブスクが自然なものを選ぶ。
> （月1万なら買い切りでも成立する。目標額が課金モデルを決める）

### 3. 5条件

| | |
|---|---|
| 1 | 市場が年商1,000万〜1億の帯にあるか（大きすぎると大手、小さすぎると届かない） |
| 2 | **その場所で実際に金が払われているか**（無料アプリの需要は、金の証拠ではない） |
| 3 | 成果物が勝手に外に出るか（月5万以上を狙うときの条件。月1万なら不要） |
| 4 | 個人が1〜2週間で作れるか |
| 5 | **自分が続けられるか** ← ここは本人しか埋められない。AIが代筆しない |

## 落とした案

### ① このさき — 働き方比較アプリ（2026-09）

| 視点 | | |
|---|---|---|
| 市場規模 | 0〜7歳の世帯 350〜400万 | ○ |
| 金額面 | **無料FP相談と無料家計簿が市場を埋めている** | ✕ |
| バズりやすさ | **家計の数字は人に見せない。拡散の燃料がゼロ** | ✕ |

**学び**: ずらす方向が「競合から離れる」方には成功していたが、
**同時に、お金が動いている場所からも離れていた。**
正しいずらしは、競合からは離れるが**お金からは離れない**方向。

成果物は `mock/` と `lp/` に残してある。作り方として使い回せる。

### ② そだつ — 月齢がはいるカメラ（2026-09-22）

調査は `docs/sodatsu.md` に全部ある（競合レビュー461件、実機検証まで）。**調査の手順自体は正しかった。**

落とした理由は2つ。

```
1. 月3万に届かない
   月3万 = 年888本の有料販売
   課金率5%と見ると → 年17,760DL 必要
   推定市場は 年3,500DL（競合の461評価 ÷ 13年 ÷ 評価率1%）
   → 5倍足りない
   しかもカメラアプリにサブスクは嫌われるので、モデルで逃げられない

2. 条件5を満たしていなかった
   本人が「使いたい」と言ったことは一度もない。
   言ったのは「競合がダサい」だけ。
   → AIが条件5を勝手に◎で埋めていた。これは埋めてはいけない欄
```

**月1万なら射程内だった。目標を3万にした瞬間に落ちた。**
企画の良し悪しではなく、**目標額と企画のサイズが合っていなかった。**

### ③ アプリブロッカー（タスク完了まで開けない）

| 視点 | | |
|---|---|---|
| 金額面 | スクリーンタイム系は課金が成立している | ◎ |
| 市場規模 | **大きすぎる。one sec / Opal / ScreenZen / スタロック / Blockin 等が既にいる** | ✕ |
| 技術 | Family Controls entitlement の審査が必要。個人だと不確実 | △ |

**学び**: 「解除条件を変える」は**ずらしではなくパラメータ変更**。
アプリにできることが1つも増えていない。

## いま生きている候補

### 保育園・幼稚園の連絡帳を、AIが下書きする（**未検証**）

```
写真を1枚選ぶ → 「今日の様子」の文章が出る → 直して送る
```

| | |
|---|---|
| 足す能力 | LLM（＋写真）。**できることが増えている＝ずらしの形** |
| 市場 | 保育園児 約270万人。毎日書く0〜2歳クラスで約120万人（**要確認**） |
| 必要な占有率 | 年3,000円 × 141人 = **0.012%** |
| 参入障壁 | **連絡帳は日本固有。海外大手が来ない** |
| 空席の根拠 | コドモン等は**園が導入するもの**。親が書く負担は減っていない（**要確認**） |
| 条件3 | 外に出ない ✕（ただし大学AIノートも同じ。月3万なら許容） |
| 条件5 | **本人が毎日書いている当事者。ただし「使いたい」は未確認** |

**次にやること（0円・5分）**

```
App Store で「連絡帳」「保育園 連絡帳」を検索し、2つだけ見る
  1. 有料 or サブスクのアプリがいるか  ← 金が払われている証拠
  2. ダサいか                          ← 入る隙
```

この2つが揃わなければ、この案も落とす。
